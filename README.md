# قرارگاه مردمی مدافعان وطن — محله کرمان

نرم‌افزار جامع و یکپارچهٔ قرارگاه (PWA + اپلیکیشن اندروید) با رابط فارسی راست‌به‌چپ، طراحی شیشه‌ای سبز–طلایی و فونت وزیر.

> **یک نرم‌افزار، سه شکل نصب:** در مرورگر (نصب روی صفحه اصلی)، اپلیکیشن اندروید (APK) و نسخه دسکتاپ/ویندوز از همان PWA.

---

## ✨ قابلیت‌ها

| بخش | توضیح |
| --- | --- |
| 🏠 **صفحه اول (داشبورد)** | تصویر انتخابی ادمین در بالای صفحه + هوای آنلاین تهران (دما و وضعیت آفتابی/بارانی/برفی…) + خبر مهم، مراسم نزدیک، آخرین گزارش‌ها و دسترسی سریع |
| 📅 **مراسم‌ها** | فهرست مراسم «پیش رو / در حال برگزاری / گذشته»، شمارش معکوس، جزئیات، مسیر روی نقشه، افزودن به تقویم و انتخاب زمان یادآوری |
| 🔔 **اعلان و یادآوری** | یادآوری خودکار پیش از هر مراسم با زمان دلخواه (۳۰ دقیقه تا ۱ روز قبل)؛ تنظیم توسط ادمین و قابل تغییر توسط کاربر. در وب با Service Worker و در اندروید با اعلان بومی (حتی برنامه بسته) |
| 💚 **نذورات و کمک‌ها** | دو روش پرداخت: ۱) پرداخت آنلاین (درگاه با الگوی لینک قابل تنظیم) ۲) کپی شماره کارت و شماره شبا + بارکد QR + انتخاب مبلغ و جهت مصرف |
| 🤝 **فرم همکاری** | انتخاب نوع همکاری (خادم مراسم، رسانه، پشتیبانی، فرهنگی، فضای مجازی، حامی مالی…)، زمان‌های مناسب، مهارت‌ها و کد پیگیری |
| 💬 **ارتباط با خادمان** | شماره‌های تماس واحدها و زیربخش **انتقادات و پیشنهادات** (انتقاد / پیشنهاد / تشکر / ارتباط) با امکان ارسال ناشناس |
| 🖼 **گزارش‌های تصویری** | آرشیو گزارش‌های **عکسی، صوتی و ویدیویی** مراسم گذشته، گالری تمام‌صفحه، پخش‌کننده صوتی با موج نمایشی و پشتیبانی از فایل آپلودی/لینک یوتیوب و آپارات |
| 📰 **اخبار** | اخبار و اطلاعیه‌های قرارگاه با جست‌وجو، برچسب، خبر سنجاق‌شده و صفحه جزئیات + اشتراک‌گذاری |
| 🔐 **پنل مدیریت ویژه** | کنترل کامل برنامه: اخبار، مراسم‌ها، گزارش‌ها، نذورات و شماره حساب‌ها، درخواست‌های همکاری، پیام‌ها، اعلان‌ها، تنظیمات هویت، تصویر هدر، هواشناسی، رمز مدیریت، پشتیبان‌گیری/بازیابی و انتشار محتوا |
| ♿ **خوانایی همه سنین** | کنترل سه‌حالته اندازه متن (عادی/بزرگ/بزرگ‌تر) در همه صفحه‌ها، دکمه‌های بزرگ لمسی، کنتراست بالا و پشتیبانی از کاهش انیمیشن |
| 📶 **آفلاین** | تمام برنامه با Service Worker کش می‌شود؛ اخبار، مراسم و گزارش‌های ذخیره‌شده بدون اینترنت هم باز می‌شوند |

## 🚀 اجرا و توسعه

```bash

npm run dev          # اجرای محلی روی http://localhost:5173
```

## 📱 انتشار در مرورگر (GitHub Pages)

1. تغییرات را روی شاخه `main` پوش کنید.
2. در گیت‌هاب: **Settings → Pages → Source: GitHub Actions**.
3. ورک‌فلوی `Deploy to GitHub Pages` (`.github/workflows/deploy.yml`) به‌طور خودکار برنامه را می‌سازد و منتشر می‌کند.

> **تنها یک مرحله دستی لازم است:** در گیت‌هاب به **Settings → Pages** بروید و در بخش *Build and deployment* گزینه **Source = GitHub Actions** را انتخاب کنید. (این تنظیم با توکن فعلی قابل تغییر خودکار نیست.) پس از آن، هر push به `main` سایت را به‌روزرسانی می‌کند.

آدرس نهایی:

```
https://husseinmilad.github.io/Gharargahekerman/
```

پس از باز شدن، از منوی مرورگر گوشی گزینه **«افزودن به صفحه اصلی» / «نصب برنامه»** را بزنید تا نرم‌افزار مثل یک اپ نصب شود (روی اندروید، iOS و ویندوز). نسخه build با مسیرهای نسبی ساخته می‌شود، بنابراین در مسیرهای زیرپوشه‌ای (مثل GitHub Pages) هم بدون تغییر کار می‌کند.

## 🤖 ساخت اپلیکیشن اندروید (APK)

پروژه اندروید با **Capacitor** آماده است (`android/`). ساخت خودکار با GitHub Actions انجام می‌شود:

- ورک‌فلوی `Build Android APK` با هر push به `main` اجرا می‌شود.
- فایل APK در **Releases** با برچسب `latest-android` منتشر می‌شود (و در تب Actions به‌عنوان artifact قابل دانلود است).

**دریافت مستقیم نسخه اندروید:**

👇 [دانلود APK نسخه ۱.۰.۰](https://github.com/husseinmilad/Gharargahekerman/releases/download/latest-android/gharargah-kerman-1.0.0.apk)

> این APK با کلید debug امضا شده و روی همه گوشی‌های اندروید (۷ به بالا) نصب می‌شود؛ برای انتشار در گوگل‌پلی باید با کلید release و به‌صورت AAB امضا شود.
- برای نسخه‌دار: تگ بزنید (`git tag v1.0.0 && git push --tags`).

### ساخت دستی روی سیستم خود

```bash
npm run build            # ساخت assets وب
npx cap sync android     # کپی assets در پروژه اندروید
cd android && ./gradlew assembleDebug
# خروجی: android/app/build/outputs/apk/debug/app-debug.apk
```

پیش‌نیاز: JDK 21 و Android SDK (از طریق Android Studio).

## 🔐 راهنمای پنل مدیریت

1. از دکمه **«مدیریت»** (پایین صفحه، سمت چپ) یا از «درباره قرارگاه» وارد شوید.
2. در نخستین ورود، یک **رمز ۴ تا ۸ رقمی** تعیین می‌کنید (هش SHA-256 ذخیره می‌شود). نشست ۴۵ دقیقه‌ای است و با هر بار خروج بسته می‌شود.
3. بخش‌ها: داشبورد · اخبار · مراسم‌ها · گزارش‌ها · نذورات · همکاری‌ها · پیام‌ها · اعلان‌ها · تنظیمات.

### کارهای رایج

| کار | مسیر |
| --- | --- |
| تغییر تصویر بالای صفحه اول | تنظیمات ← «تصویر بالای صفحه اول (هدر)» ← انتخاب تصویر |
| تنظیم هوای تهران | تنظیمات ← «نمایش هوای آنلاین» (پیش‌فرض تهران با مختصات ۳۵٫۶۸۹۲ / ۵۱٫۳۸۹) |
| تنظیم شماره کارت و شبا | نذورات ← حساب‌ها (شماره کارت ۱۶ رقمی و شبا ۲۴ رقمی، بدون IR) |
| فعال‌کردن پرداخت آنلاین | نذورات ← «الگوی لینک پرداخت» با `{amount}` (مبلغ به ریال) |
| تعیین زمان یادآوری مراسم | مراسم‌ها ← ویرایش ← «اعلان و یادآوری» |
| تغییر زمان‌های پیشنهادی یادآوری | تنظیمات ← اعلان‌ها |
| ارسال اعلان فوری | اعلان‌ها ← اعلان جدید |
| تغییر عنوان و شعار | تنظیمات ← هویت قرارگاه |

> ⚠️ شماره کارت/شبای نمونه در داده‌های اولیه، «تکمیل‌نشده» علامت می‌خورند و در برنامه با هشدار نمایش داده می‌شوند تا نمایش شماره اشتباه به مردم رخ ندهد. آن‌ها را از پنل مدیریت جایگزین کنید.

## 🌐 انتشار محتوا برای همه کاربران

داده‌ها روی دستگاه هر کاربر ذخیره می‌شوند (بدون سرور و بدون نقض حریم خصوصی). برای رساندن محتوای جدید به **همه** کاربران:

1. در پنل: **تنظیمات ← انتشار محتوا ← دریافت فایل محتوا** (فایل `app-state.json` دانلود می‌شود).
2. آن فایل را در مخزن، مسیر `content/app-state.json` جایگزین کنید.
3. تغییرات را commit و push کنید (یا مستقیم فایل را در GitHub ویرایش کنید).

هنگام باز شدن برنامه، هر کاربر فایل جدید را دریافت می‌کند (یا از همان مسیر: تنظیمات ← دریافت محتوای تازه). اطلاعات شخصی کاربران (فرم‌های همکاری و پیام‌ها) هرگز در این فایل قرار نمی‌گیرد. ادمین می‌تواند با اسکریپت هم منتشر کند:

```bash
npm run publish:content -- content/admin-backup.json
```

## 🗂 ساختار پروژه

```
src/
├── App.tsx                 # مسیریابی و قالب کلی
├── pages/                  # صفحه‌های عمومی (خانه، مراسم، نذورات، …)
│   └── admin/              # پنل مدیریت (۹ بخش + اجزای مشترک)
├── components/             # اجزای مشترک (ناوبار، هواشناسی، شیت، تصویر امن)
├── lib/
│   ├── store.tsx           # وضعیت برنامه + ذخیره‌سازی محلی + فایل‌رسانه
│   ├── remote.ts           # همگام‌سازی محتوا از گیت‌هاب
│   ├── notifications.ts    # اعلان وب و اندروید + زمان‌بندی یادآوری
│   ├── jalali.ts           # تاریخ جلالی و ارقام فارسی
│   ├── weather.ts          # هواشناسی Open-Meteo
│   └── router.tsx          # مسیریابی هش‌محور
├── sw.ts                   # Service Worker (كش آفلاین و اعلان)
└── styles.css              # سیستم طراحی «شیشه سبز» + فونت وزیر
content/app-state.json      # محتوای منتشرشده برای همه کاربران
android/                    # پروژه Capacitor اندروید
scripts/                    # ساخت آیکون، بررسی تقویم، تست دود و ابزارها
```

## 🔒 حریم خصوصی

- داده‌های برنامه در `localStorage` و فایل‌های رسانه در `IndexedDB` همان دستگاه نگهداری می‌شوند.
- هیچ سرور واسط یا ردیاب تحلیلی وجود ندارد؛ تنها اتصال خارجی، سرویس هواشناسی Open-Meteo است.
- رمز مدیریت فقط به شکل هش SHA-256 ذخیره می‌شود.
